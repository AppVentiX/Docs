# AppVentiX 5.1.44 release notes

- Enhanced Entra ID and AVD integration, dependency modules are no longer required
- App-V global publishing fix: Resolved an issue where the event log entry could exceed size limits when processing a high volume of global publishing tasks
- Improved MSIX file type association (FTA) support for both in-package and native executables
- User settings enhancements: Improved shortcut and group policy processing, external tasks can now be executed without waiting for completion
- Agent refresh UI improvements: Added real-time progress visibility and resolved an issue where the refresh window did not close correctly
- Central View console updates: Improved UI behavior and layout consistency to enhance overall user experience
