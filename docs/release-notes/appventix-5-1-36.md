# AppVentiX 5.1.36 release notes

- Settings can now be organized into folders within the console for improved visibility and management
- Column settings are now retained when restarting the console
- The Microsoft Store import feature has been enhanced
- Fixed an issue where users who were members of an excluded group could still see the refresh interface during login
- Fixed an issue where QWORD registry value types were not handled correctly
