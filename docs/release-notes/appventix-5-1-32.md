# AppVentiX 5.1.32 release notes

- Console improvements: Fixed a sorting issue in assignments and new search filters have been added
- App-V: Modify shortcuts directly from the console and edit deployment configurations using the new embedded editor
- MSIX: Updated package editor for improved usability
- User Settings: Added support for native shortcut creation (Start Menu and Desktop). Improved handling of registry HEX values and resolved an issue where certain GPO settings could not be configured.
- Agent Configuration: Added support for excluding user groups from application and User Settings processing. Domain Admins are excluded by default.
