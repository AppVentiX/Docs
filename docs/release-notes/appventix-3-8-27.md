# AppVentiX 3.8.27 release notes

- An issue where App-V packages were not published globally at machine startup has been fixed
- Some MSIX packages could not be registered (unable to update all user store event was logged), this has been fixed
- When Community Edition was used with more than three packages, the console could display an error message upon startup
- The "Update Deployment Configuration Files" feature for App-V has been optimized
