# Machine Groups

Machine Groups define the scope of your deployment and allow you to segment it by environment or device type, such as Production, Test or by machine collection (AVD\Citrix), or Entra ID laptops.

A Machine Group is built dynamically from an OU or group in Active Directory, or from Entra ID machines. For each Machine Group, you can configure agent settings and content stores.

You can find how to setup and configure machine groups in the [Quickstart - Create Machine Group(s)](../quickstart/create-machine-groups.md)
